# FediFox

Firefox add-on to like, share, follow, reply to and mention the ActivityPub
object or actor behind the page you are looking at, from your own fediverse
account.

- [Test links](test-links.md): every link form FediFox reacts to, with real targets to click.
- [Architecture](architecture.md): how the add-on is built.
- [Manual test checklist](testing.md): what to click through before a release.
- [Wire examples](examples/): the exact requests FediFox sends to the outbox.

The code is on [GitHub](https://github.com/pfefferle/fedifox).
